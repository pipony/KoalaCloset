01

一分钟上手

QUICK START

整个网站只有五个常驻页面 + 三个按钮入口，记住这张地图就够了：

Ⅰ衣柜 日常主页面

所有衣服的格子墙。顶部搜索框说一句话就能找衣服；旁边问 AI 按钮处理搜不出来的问题。

Ⅱ套搭 今天穿什么

顶部「AI 帮我搭」出一套新方案；下方按温度带 + 场景过滤已存套搭（这条路断网也能用）。

Ⅲ尺码档案

基准款管理 + 任何两件衣服的尺寸并排对比（超差标红）。

ⅣAI 标注

衣柜描述卡的「体检」——AI 看图补空字段、挑疑似填错的，你逐项勾选才生效。

Ⅴ避雷清单

被否掉的搭配和理由都攒在这里，AI 搭配会自动避开。

＋三个按钮入口

页头：搭配板（自由拼一套）· 买前比对（想买的衣服丢截图）· 录入新衣

新手最短路径：录 10 件衣服（每件半分钟，见 02）→ 存 3 套套搭 → 明早出门前打开套搭页。数据越攒越多，AI 越来越懂你。
02

录衣服：半分钟一件

NEW ENTRY
1传商品图点「+ 录入新衣」→ 商品图区传电商页保存的图
→
2点 AI 预填「AI 预填描述卡」— AI 看图选好 9 组词表和名称
→
3扫一眼改错不对的 pills 点两下改掉，词表外的值进不来
→
4存入衣柜尺寸表/购买码/合身反馈顺手填了更好，也可后补

描述卡是什么

每件衣服一张口径统一的文字卡：主色 / 图案 / 厚薄 / 版型 / 长度 / 领型 / 面料 / 弹性 / 风格。它是找衣服、买前查重、AI 搭配共用的数据底座——卡填得越准，后面全都越聪明。

合身反馈（哪里紧/松/长/短）是尺码对照时真正值钱的信息；拿不准合不合身的衣服再传一张正面全身实拍。
03

找衣服：说人话就行

SEARCH

本地搜索（断网可用，主路径）

衣柜页顶部搜索框，像日常说话一样输入：明天 16 度 通勤 白色的薄上衣 牛仔裤——解析出的条件会变成一排 chips（主色：白 ×　厚薄：薄 ×），点 chip 可以改值或删掉再查，不是一锤子买卖。

问 AI（联网，手动点击）

本地搜索搞不定的意图型问题——有哪些显瘦的上衣？ 见家长穿什么好——输入后点旁边的 问 AI 按钮。AI 基于你的衣柜文字卡回答，命中的衣服卡片直接列在下面，点进去看详情。

问 AI 只发文字卡，不发任何照片；每次都要你亲手点按钮才联网。codex 不可用时会出现「复制提示词」按钮，粘到 ChatGPT 网页问也一样。
04

今天穿什么

OUTFIT

离线主路径：过滤已存套搭

套搭页选温度带（严寒 ≤5° / 凉 5–15° / 舒适 15–25° / 热 ≥25°）和场景（通勤/休闲/运动/约会/居家），已存的套搭直接筛出来。没网也照样用。

AI 帮我搭（联网，手动点击）

1说条件温度带 + 场景 + 一句附加要求（如"想显利落一点"）
→
2AI 出一套约半分钟，草稿带标题和搭配理由
→
3你说了算满意 → 存为套搭；不满意 → 点理由标签
→
4越用越准不喜欢的自动进避雷清单并立刻换一套
两个勾选框口径
带上我的套搭当口味参考默认不勾——勾了才把已存套搭发给 AI 当口味参考（每次先问，你自己定）
视觉复核默认关——开启后 AI 会看所选衣服的照片给复核意见（这是唯一会发衣柜照片的场景）
AI 出的是未存档草稿，点「存为套搭」才真正入库。它的取材优先级是定死的：你的明确要求 > 已存套搭 > 配色·量感·正式度 > 自由发挥。

自由拼一套：搭配板

页头「搭配板」——手动挑衣服组合（待买的比对卡也能当虚拟卡片放进来试配），拼好存档时可标温度带 + 场景；套搭详情页还能写备注、传上身图。

05

想买衣服：先比对，再下单

PRE-PURCHASE
1丢截图页头「＋ 买前比对」→ 拖 1~8 张卖家秀/详情页截图，一个字段都不用填
→
2AI 看图比对自动提取信息，对照衣柜和基准款给结论四件套
→
3看结论建议码数+理由 / 有没有重复的 / 能配什么 / 一句话买不买
→
4二选一买了 → 转正式档案（补齐 AI 没认出的字段）；没买 → 丢掉

结论页下方还有三块本地印证（断网也能算）：和基准款的尺寸并排表（超差标红）、衣柜查重打分（≥6 高度相似 / ≥3 有些像）、能配几套。AI 说它的，数字说数字的，互相印证。

比对是临时动作——看完就转正或丢掉，截图文件夹会一并清理，不攒垃圾。发送内容 = 你的截图 + 衣柜文字卡，不发衣柜照片。
06

尺码档案：买对码的地基

SIZE

基准款（2~3 件非常合身的衣服）

在它们的编辑页勾上「基准款」。之后买前比对的尺码建议、尺码页的并排对比，全都以基准款为标尺。对照按类匹配：同细分优先（短袖跟短袖比），同大类兜底，跨大类不比。

AI 标注：描述卡体检

「AI 标注」页勾几件衣服（一批最多 12 件）→ AI 看商品图对照已填的卡 → 给两类建议：

补空 · 默认勾选

字段空着的，AI 给出建议值，默认已勾，点「应用」就填上。

改动 · 默认不勾

已填但 AI 认为和图对不上的，显示「现值 → AI 认为是」，你不勾就绝不改——动你的数据必须你亲手点头。

07

AI 功能总览

AI MAP

四个 AI 功能走同一条本地通道（Codex CLI），没有任何 API Key，全部手动触发、界面常显发送内容：

买前比对PRE-PURCHASE

触发：丢截图后点「开始 AI 比对」　发送：新衣截图 + 衣柜文字卡（不发衣柜照片）

约 1~2 分钟 · 消耗少量额度 · 结论四件套 + 本地印证

AI 帮我搭STYLIST

触发：点「AI 出一套」　发送：衣柜文字卡 + 避雷清单（总是）+ 已存套搭（勾选才发）+ 所选衣服照片（勾视觉复核才发）

约半分钟 · 草稿不落库 · 不喜欢点标签即换一套

AI 标注ANNOTATE

触发：录入页点「AI 预填」/ 标注页点「AI 体检」　发送：所选衣服的商品图 + 词表 + 当前文字卡

预填约半分钟、体检约 1 分钟 · 建议逐项确认才生效

问 ChatGPTASK

触发：输入问题点「问 AI」　发送：衣柜文字卡 + 问题（纯文字）

约半分钟 · 回答仅供参考，不写任何数据 · 失败可复制提示词

08

隐私与数据

PRIVACY
东西存在哪会出你的电脑吗
衣服档案 / 图片 / 套搭 / 避雷项目里的 data/ 文件夹（人可读 JSON + 图片）不会。全本地，无云同步，无账号
ChatGPT 登录态~/.codex/auth.json（Codex CLI 自己管理）网站代码不碰它，也不在仓库里
AI 任务文件夹data/ai-tasks/（截图 + 文字卡 + 结果）比对件丢掉时一并清理
代码仓库GitHub（代码与文档）data/ 在 .gitignore 里，私人档案永不入库

联网铁律

① 只有你点按钮才联网，绝不自动发起；② 衣柜存量档案只发文字卡——例外只有两处且都要你主动：买前比对的新衣截图（那是你提供的输入）、视觉复核勾选时的所选衣服照片；③ AI 永远不默默改数据——标注建议要逐项勾选，搭配是草稿要你确认。

备份：目前靠手动——定期把整个 data/ 文件夹拷到移动硬盘或网盘。衣服录多了这件事最重要。

常见问题

FAQ
问题怎么办
AI 按钮报「codex CLI 未安装」终端跑 npm i -g @openai/codex（本机已装过则检查 PATH）
报「Codex 未登录」终端跑一次 codex login（用 ChatGPT 账号登录，之后一直复用）
AI 一直转圈/超时多为网络问题——检查代理是否开启；网站会自动走系统代理，直连模式需代理在 TUN/增强模式
额度用完了Plus 的 Codex 有额度上限，次日恢复；批量标注分批跑（每批 ≤12 件）
断网了还能用吗能。衣柜/录入/尺码/套搭过滤/本地搜索/避雷全部离线可用，只有 4 个 AI 按钮不能用
怎么启动网站终端 cd 到项目目录 → npm start → 浏览器开 localhost:4173
AI 填错了怎么办词表外的值它填不进来；词表内选错的，录入/编辑页点两下 pills 改掉即可——服务端校验永远兜底
数据想搬家/换电脑整个项目文件夹拷走即可（含 data/）；新机器装好 Node 和 codex CLI 就能跑
记住一个原则：AI 在这个网站里永远是助手不是管家——它提建议、给草稿、做预填，落不落地、改不改数、存不存档，每一次都是你说了算。
